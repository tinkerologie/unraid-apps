### Unraid Apps

Community Apps repository for Unraid plugins by [Ruaan Deysel](https://github.com/ruaan-deysel).

#### Layout

- `ca_profile.xml` — repository profile for Community Apps
- `plugins/vault.xml` — [Vault Backup Manager](https://github.com/ruaan-deysel/vault)
- `plugins/unraid-management-agent.xml` — [Unraid Management Agent](https://github.com/ruaan-deysel/unraid-management-agent)

#### Support

Per plugin: use the Unraid forum thread linked on each app, or open an issue on the matching GitHub project.

If these plugins are useful to you, consider [sponsoring](https://github.com/sponsors/ruaan-deysel). ❤️
